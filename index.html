Integration Source

Simulate a network monitoring alert from SolarWinds and send it to your JSM Ops integration.

JSM Integration Configuration

The simulator uses hard-coded source-specific configuration. The SolarWinds tab posts the SolarWinds field convention (ActionType, AlertMessage, alias, AlertDescription, Severity, source, tags) to the SolarWinds integration endpoint. The BMS tab posts the JSM Ops v2 alert format. Keep integration keys private and use the exact endpoint configured for each integration.
